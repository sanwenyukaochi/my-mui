# 🐱 Cute Grotesque（喵喵衍生怪萌）UI 设计体系 Skills

## 一、视觉风格体系构建能力

### 1. Cute Grotesque 美学构建

* 构建“可爱 × 阴郁 × 轻怪诞”的视觉世界观
* 保留暗色基调，但去除血腥与压抑感
* 使用圆润比例替代尖锐冲击
* 通过夸张表情与比例制造怪萌张力
* 在“安全感”与“异样感”之间建立平衡

### 2. Dark Pastel 配色系统设计

* 低饱和暗色背景（Soft Dark Base）
* 灰粉 / 灰紫 / 奶灰强调色
* 冷灰蓝辅助层级色
* 柔和阴影而非硬对比黑影
* 控制情绪张力而不产生压迫感

示例色板：

* Soft Dark: #1F1E24
* Dusty Pink: #C48FA1
* Muted Purple: #7C6A9A
* Fog Blue: #6E7C8C
* Cream Gray: #D9D3C9
* Soft Shadow: #141418

## 二、质感与形态表达能力

### 1. Soft Texture UI System

* 轻噪点纹理叠加（柔和而非脏污）
* 蜡笔式描边 / 手绘轮廓
* 不规则但圆润的边角处理
* 层叠式卡片结构营造“贴纸感”
* 阴影带轻微模糊，增强柔软度

### 2. 技术实现能力

* SVG 手绘路径模拟自然轮廓
* CSS Filter 实现柔和暗化
* 轻微 transform 抖动增强“活物感”
* 渐变叠加制造暗色深度
* 变量化控制质感强弱

## 四、交互与动效表达能力

### 1. 情绪化交互设计

* Hover 状态轻微偏粉 / 偏紫
* Active 状态压缩 + 轻错位
* 微抖动（Subtle Jitter）增强生命感
* 轻柔渐变过渡替代强闪烁效果

### 2. 动效控制能力

* transform-based 物理压缩反馈
* 柔和 cubic-bezier 曲线控制
* 情绪节奏匹配（慢节奏呼吸式动效）
* 小幅度浮动动画（Floating Motion）
