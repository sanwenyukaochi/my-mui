# 涂鸦手绘 · 手帐风格 组件库设计规范

---

## 一、设计定位

**风格方向：** 涂鸦手绘 + 手帐风格 + 贴纸质感

**品牌气质：**

* 轻松随性
* 有温度
* 可爱但不幼稚
* 像一本可以随手写写画画的手帐本

**设计目标：**
构建一套统一的 React + MUI 组件视觉系统，避免在单个组件内重复写 sx，实现可扩展的主题化管理。

---

## 二、核心风格关键词

1. 手绘感
2. 贴纸质感
3. 纸张肌理
4. 非对称圆角
5. 黑色描边

---

## 三、颜色体系（手帐色盘）

### 主色

* 奶油黄 #FFF3C4

### 辅助色

* 薄荷绿 #BFEAD7
* 蜜桃粉 #FFC8DD

### 强调色

* 番茄红 #FF6B6B
* 涂鸦黑 #222222

### 背景色

* 米白 #FFFDF7

---

## 四、字体规范

**统一字体：**

```
src/assets/fonts/DFGirl.ttf
```

### 规则

* 全局 Typography 强制使用 DFGirl
* 禁止 fallback 到系统默认字体
* 禁止 uppercase

---

## 五、视觉语言规则

### 1️⃣ 边框规则

* 必须有明显黑色描边
* 2px–3px 粗线条
* 不允许无边框按钮

示例逻辑：

```
border: 3px solid #222
```

---

### 2️⃣ 圆角规则

* 禁止标准 8px / 12px 对称圆角
* 使用不规则椭圆圆角

示例思路：

```
borderRadius: 18px 14px 20px 12px / 14px 22px 12px 18px
```

---

### 3️⃣ 阴影规则

* 不使用模糊阴影
* 使用“块状偏移阴影”
* 模拟贴纸浮起

示例逻辑：

```
boxShadow: 4px 4px 0 #222
```

---

### 4️⃣ 动效规则

* hover 微微抬起
* active 微微按下
* 动画时间 120ms–150ms
* 禁用 Material ripple

---

## 六、组件覆盖范围

基础组件必须统一风格：

* Button
* TextField / Input
* Checkbox
* Radio
* Switch
* Card
* Chip
* Dialog
* Tabs

禁止只做 Button 单组件风格。

---

## 七、暗黑模式策略

❌ 不支持暗黑模式

原因：
手帐风基于纸张质感，暗色背景会破坏整体视觉语义。

---

## 八、架构建议

推荐目录结构：

```
theme/
 ├── palette.ts
 ├── typography.ts
 ├── components/
 │    ├── button.ts
 │    ├── input.ts
 │    ├── checkbox.ts
 │    ├── card.ts
 └── index.ts
```

使用 createTheme 统一管理，不在业务组件内写重复样式。

---

## 九、设计原则总结

* 每个组件都像“贴纸”
* 每个交互都有一点手写温度
* 线条要粗
* 颜色要柔和
* 布局要留白
* 视觉要有呼吸感

---

这是一套完整可扩展的涂鸦手帐设计系
